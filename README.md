# Voltix Motors — protótipo de catálogo

Conceito visual da ServAgency baseado na estrutura do [VÉLO](https://oluisvi.github.io/velo-mobilidade/).

- Mobile-first, com três direções visuais alternáveis.
- Catálogo demonstrativo com busca, filtros, favoritos, comparação, seleção e contato pelo WhatsApp.
- Cidade/área observada: Porto Ferreira / SP.
- O WhatsApp encaminha para o número já usado na conversa: +5519990037604.
- Produtos, imagens, categorias, preço, estoque, endereço completo e serviços permanecem demonstrativos/a confirmar com a loja.
- Esta publicação é um protótipo; escopo comercial, prazo, preço e contratação não foram acordados.

Abra `dist/index.html` localmente. GitHub Pages publica o conteúdo de `dist/` via Actions.
